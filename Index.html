The generated .ics file intentionally omits all VALARM reminder tags. However, some versions of Outlook automatically apply your personal default reminder to newly imported items.

How to Import into Outlook

  • Outlook Desktop: Double-click the downloaded .ics file, or use File → Open & Export → Import/Export → Import an iCalendar (.ics).
  • New Outlook / Web: Open Calendar → Add calendar → Upload from file, select your .ics file, and pick your target calendar.

If Outlook Still Adds Default Reminders

  • Classic Outlook: Go to File → Options → Calendar, temporarily uncheck Default reminders, import the file, then re-enable it.
  • New Outlook / Web: Open Settings (gear) → Calendar → Events and invitations, set Default reminder to None while importing, then switch it back.
